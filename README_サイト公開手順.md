# 宇邇宮人物事典 — GitHub Pages 公開手順

1. このフォルダにある `index.html`、各 `.html`、`assets`、`sitemap.xml` 等を、フォルダ自体ではなく**中身**として、GitHubリポジトリ `uni-tadayasu/uninomiyatadayasushinnou.github.io` の直下へアップロードします。
2. GitHub の **Settings → Pages** で、Source を **Deploy from a branch**、Branch を **main**、Folder を **/(root)** にします。
3. 公開サイト：`https://uni-tadayasu.github.io/uninomiyatadayasushinnou.github.io/`
4. 必要に応じて Google Search Console にサイトを登録し、`sitemap.xml` を送信します。

「編集」「履歴を表示」タブは当該GitHubリポジトリにリンクします。インタラクティブなWikiのサーバー機能は含みません。

このサイトはWikipedia公式サイトではなく、創作人物の独立百科事典です。
