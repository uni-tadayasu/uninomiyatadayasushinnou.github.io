宇邇宮忠靖親王 — 宇邇三つ葉（黒色・透明）Wikipedia風創作人物事典

【公開方法】
1. ZIPを展開してください。
2. 展開した中の index.html、assets フォルダー、sitemap.xml 等すべてを GitHub リポジトリ直下へ配置してください。ZIPファイルだけをGitHubへ置いても公開されません。
3. https://github.com/uni-tadayasu/uninomiyatadayasushinnou.github.io の Settings → Pages を開き、Build and deployment: Deploy from a branch、Branch: main、Folder: /(root) を選択します。
4. 公開先: https://uni-tadayasu.github.io/uninomiyatadayasushinnou.github.io/

【更新内容】

・家紋解説と検索用の説明文を修正

【注意】
Wikipedia本体ではなく、独立した創作人物事典です。実在する皇族の身分や血縁を示すサイトではありません。検索結果への掲載と上位表示は保証されません。
